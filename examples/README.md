# Writing examples

Posts you like, used by every draft as **style references only** (hook, rhythm, length, how the closing question is phrased). The model is told never to reuse their sentences, facts, numbers or names, and the guardrail rejects a draft that shares a long run of words with an example.

Add one:
- **Someone else's post:** open an issue with the label `example`. Title: why you like it. Body: the post text. It is saved here and the issue closes.
- **One of your own drafts:** comment `/example` (optionally `/example great hook`) on its issue.

To stop using an example, delete its file. `README.md` itself is never used as an example.
